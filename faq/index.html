Frequently Asked Questions

General

What is BTD5 Restored?
BTD5 Restored is a fan-made port of Bloons TD 5, made in Godot 4.
Is this an official release?
No. This is a fan project and is not affiliated with or endorsed by Ninja Kiwi.
Why did you make this?
The original Flash version can only* be played on Ninja Kiwi Archive, has sub-par performance, and all of the features that required a server or an online connection don't work anymore. This project aims to restore (and improve) that functionality. *Some sites unofficially host BTD5 .swfs.
Why not just play the Steam / mobile versions of BTD5?
The Steam and mobile versions have several differences from the Flash version, the most notable one being different artwork and graphics. The vector graphics from the Flash version look nice and I wanted to bring them back. Also, the Steam and mobile versions cost money and cannot be played in a web browser.

Legal / Copyright

Is this legal?
I'm not a lawyer. This is just a fan project that aims to preserve gameplay. I do not make any money off of it.
Do you use the original assets?
Yes. The assets used in BTD5 Restored are from the original Flash version of BTD5. They have been ripped from the original .swf file using JPEXS Free Flash Decompiler.

Gameplay & Features

Latest update?
You should check the GitHub Repository for the very latest updates, but currently, I'm working on rewriting the entire project in C# due to GDScript being too slow (in some situations, even slower than Flash/AS3). You can read more about it and see its current progress here.
Which features are restored?
As of now, bloon movement, rounds, and a few basic towers have been ported. In the future, I plan to expand to almost (if not all) of the original game's content.
Are there microtransactions or paid content?
No. The game does not implement or require the original in-app purchase systems, and it never will. Any feature that relied on spending real money (such as "NK Coins") will be replaced with a free alternative that can be earned in-game.

Bugs & Reporting

How do I report a bug?
Please open an issue using the GitHub issue tracker. Consider checking if the issue has already been reported to avoid duplicates.
Where can I see the updates?
Check the GitHub releases and commits. There is no update log page as of now.
